# i18n — EN + SR (live)

## Implementation

- Dictionary: **`lumora/i18n.js`** (`G8I18n`)
- Persist: `localStorage` key `g8-lang`
- URL: `?lang=sr` or `?lang=en` (replaceState on switch)
- Early boot in `index.html` / legal pages sets `html[data-lang]` + `lang` before paint
- Toggle: EN | SR in header, footer, mobile menu

No `/en` `/sr` path prefixes on the static deploy. SEO uses `hreflang` links in HTML + sitemap.

## Rules

- Default: prefer saved lang → `?lang` → browser `sr`/`hr`/`bs` → else **EN**
- Translate marketing + meta + FAQ JSON-LD strings via keys
- **Do not** mix languages in one view
- Serbian: rewrite for local market (**Vi**, full sentences) — not a calque of EN
- Shared: brand **G8 Flow**, plan names Launch / Growth / Custom, case URLs, Calendly, email

## Must keep in sync

When adding UI strings, add keys to **both** `en` and `sr` objects in `i18n.js`, and wire `data-i18n` / `data-i18n-html` / `data-i18n-aria` / `data-i18n-placeholder` as needed.
