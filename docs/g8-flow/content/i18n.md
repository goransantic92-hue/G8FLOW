# i18n — EN + SR

## Approach

- Default locale: detect or prefer **EN** on first visit; persist choice in `localStorage`
- Toggle in nav + footer: **EN | SR**
- All marketing copy lives in message dictionaries (or `content/*.md` keys) — no mixed languages in one view
- Routes (Next.js): `/en` and `/sr` **or** single path with client/server locale switch — prefer `/en` + `/sr` for SEO

## Must translate

- Nav, hero, process, cases blurbs, testimonials quotes, pricing, CTA band, footer labels
- Meta title/description per locale
- Legal pages (drafts in both languages)

## Can stay shared

- Brand name **G8 Flow**
- Plan names: Launch / Growth / Scale
- Live case URLs
- Logo wordmark

## SEO

- `hreflang` en ↔ sr when both ship
- Unique title/meta per locale
- One H1 per locale page
