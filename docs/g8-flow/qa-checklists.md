## Hero / conversion

- [ ] Value-led H1 readable in 5 seconds
- [ ] Supporting subhead: who + how
- [ ] Dominant visual (photo / motion)
- [ ] Two CTAs with action language
- [ ] Trust cue near CTAs (result line or client names when available)

## Message & content

- [ ] One core promise ≤20 words
- [ ] Outcomes over features
- [ ] Process in 3–5 steps
- [ ] Cases with measurable or concrete outcomes
- [ ] Testimonials: name + role + human quote + photo
- [ ] Pricing: 3 plans, one highlighted, value framing
- [ ] FAQ only if objections block conversion (optional v1)
- [ ] Plain language, scannable paragraphs

## UX / usability

- [ ] Primary path obvious on mobile
- [ ] Tap targets ≥44px
- [ ] Focus states visible on navy/blue
- [ ] Carousel keyboard (arrows) + aria
- [ ] `prefers-reduced-motion` path for hero
- [ ] No dead ends; footer contact present

## SEO / content tech

- [ ] Unique title + meta description
- [ ] Single H1; logical H2s per section
- [ ] Image alts that describe purpose
- [ ] OG/Twitter preview image
- [ ] Internal anchors / nav labels clear
- [ ] JSON-LD Person or ProfessionalService when ready

## Performance / launch

- [ ] LCP ≤2.5s on mobile (hero optimized)
- [ ] CLS ≤0.1; INP ≤200ms
- [ ] Fonts: preload + `font-display: swap`
- [ ] Lazy-load below-fold media and heavy FX
- [ ] HTTPS, custom 404, robots + sitemap
- [ ] Analytics events on both CTAs
- [ ] Privacy / terms linked
- [ ] No placeholder content in production

## Explicitly out of scope for v1

Local GMB/NAP packs, ecommerce checkout, fake scarcity timers, multi-locale hreflang, blog CMS, competitor slugfest tables.
